# 运行时设计

Agent Runtime 负责把一个任务目标推进到交付：循环调模型、执行工具，在回合边界持久化，并在需要人工审批时挂起、之后续跑。它不依赖任何图编排框架，核心是一个只有几行的异步循环，加一张 SQLite 表。

## 设计原则

1. **控制权在模型。** 下一步做什么由模型的回复决定。代码不设固定阶段、不设硬编码路由，只提供护栏与落盘。
2. **循环只认四样东西**：工具集、上下文装配器、会话草稿、模型句柄。其余能力都在循环外，挂在固定接缝上。
3. **运行边界确定**：额度耗尽按模型接口错误处理，按异常停，检查点保留，可续跑。
4. **提交点即恢复点。** 一个回合有两次提交（派发前、结果后）；尾部的未配对调用就是"可能已执行"的信号。
5. **挂起不是阻塞。** 等待审批时任务退出，之后由决策到达重新拉起，不在内存里持有悬空协程。
6. **护栏是确定性代码。** 权限、重复指纹、连续错误由代码强制，模型只能被告知，不能决定是否生效。
7. **transcript 只追加。** 折叠与压缩只发生在装配视图，原文始终可查。
