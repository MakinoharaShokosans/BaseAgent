## 一页纸

- **一个核心进程**：API 与运行时同进程，两个独立 sidecar（命令沙箱、网络检索），可选的 MCP 子进程，浏览器控制台。全部只监听回环地址。
- **一个纯 agent loop**：调模型、跑工具、追加结果，无工具调用即结束；没有阶段和路由，回合边界提交检查点。
- **三道防线**：权限分层（要不要同意）、沙箱（获准之后能做什么）、信任隔离（内容能不能当指令）。
- **没有预算**：额度耗尽按模型错误停止；保留的刹车是取消、重复拦截、金丝雀终止与单次调用超时。
- **四条观测旁路**：事件、轨迹、日志、追踪，全部不影响主流程。
- **没有**：LangGraph、LangChain、RAG、向量库。
