# 0007 能力挂载：前缀不变，激活只追加

- 状态：**已采纳并实施**（后端）
- 影响：[MCP](../04_tools/04_mcp.md)、[Skills](../04_tools/05_skills.md)、[工具系统](../04_tools/01_tool_system.md)、[提示词装配](../03_context/03_prompt_assembly.md)、[工具执行](../02_runtime/06_tool_execution.md)

## 背景

技能与 MCP 工具都是"可挂载的能力"，原有设计只解决了静态挂载：任务启动时扫描并冻结，主工具集会话内固定。留下三个缺口：

1. MCP 工具的完整 Schema 全部进 `tools` 字段。服务器一多，常驻成本是"Schema 体积 × 之后所有调用"，且任何一个服务器上下线都使整段前缀失效。
2. 技能的两阶段披露（清单常驻、正文按需）是单独的机制，MCP 没有对应物。
3. 没有规定任务中途出现的变化（新技能、服务器上线、工具列表变更）何时生效。

## 决定

1. **挂载分两种动作，缓存代价不同。**

   | 动作 | 例子 | 生效 | 缓存影响 |
   |---|---|---|---|
   | **激活** | `load_skill`、`mcp_describe` | 立即，结果作为 `tool` 消息追加 | 无 |
   | **变更挂载集** | 新增或修改技能、服务器启停或上下线、列表刷新、配置改动 | **下一个任务的准备阶段** | 清单、索引或 `tools` 之后的前缀失效一次 |

   任务内不存在"热挂载"：不在任务中途改 `tools`，不向前缀插入。模型需要的能力必须已经在索引里，经激活使用。

2. **MCP 工具分两种暴露方式**，按服务器配置 `exposure`：
   - `pinned`：Schema 直接进 `tools`，行为同普通工具，适合少量高频工具。
   - `deferred`（默认）：Schema 不进 `tools`。第 2 段常驻一份**索引**（`mcp.index`），只有工具名与一句话描述；模型用内置的 `mcp_describe` 取完整 Schema（追加为观察值），再用 `mcp_call` 调用。
3. **`mcp_call` 是代理，不是权限主体。** 工具包装层在校验调用的第一步把 `mcp_call(name, arguments)` 解析为对目标工具的调用，权限、审批、指纹、幂等、信封、超时全部按**目标工具**判定。transcript 里保留模型原始发出的代理调用，不改写。
4. **与技能统一为"索引 + 激活"**：常驻只放名字和一句话，正文或 Schema 由模型显式取，取回的内容追加进 transcript、折叠豁免。技能不能挂载工具，只能在 `load_skill` 的结果里提示它依赖哪些延迟工具。
5. **索引只在成功刷新后变化。** 它由各服务器**最近一次成功的、通过消毒的**工具列表生成，不反映瞬时可用性：服务器暂时连不上不改索引（调用失败即可），避免状态抖动反复使前缀失效。
6. **子智能体不用代理。** 被授予的 MCP 工具直接进它自己的 `tools`：子智能体有独立请求，缓存互不牵连。

## 放弃了什么

- **任务内热挂载（改 `tools`）。** 每次都使其后整段前缀失效，而且让权限与审批的判定对象随任务变化。
- **模型自行启用服务器。** 启用一个服务器等于授权其全部通过消毒的工具，这是用户的决定，不是模型的。
- **订阅 `listChanged` 并立即生效。** 只当作"需要刷新"的信号，仍在任务准备阶段处理。

## 后果

- `tools` 字段只含内置工具、`pinned` 的 MCP 工具和（存在延迟工具时的）`mcp_describe`、`mcp_call`，MCP 规模增长不再推高每次请求的固定成本。
- 代价是延迟工具首次使用多一轮 `mcp_describe`。高频工具设为 `pinned` 即可消除。
- 延迟工具的 Schema 在 transcript 里：被任务内压缩或折叠丢掉后，`mcp_call` 会因"未取过 Schema"失败并提示重取，不会带着猜出来的参数调用。
- 索引的内容来自第三方描述，在稳定前缀里属于**不可信数据**，须消毒后截断，并包不可信信封。

## 迁移

| 现有 | 去向 |
|---|---|
| `mcps/` 管理器返回全部工具 | 增加按 `exposure` 区分的快照；缓存每个服务器最近一次成功的消毒列表 |
| `build_builtin_tools` | 存在延迟工具时注册 `mcp_describe`、`mcp_call` |
| 工具包装层 | 校验阶段先解析代理调用 |
| 提示词装配第 2 段 | 技能清单之后加 MCP 索引信封 |
| 配置 `[mcp]` | 加 `exposure`、`index_max_listed`、`index_desc_chars` |
