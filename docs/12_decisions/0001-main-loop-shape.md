# 0001 主循环保留五阶段

- 状态：**已采纳**
- 影响：[02_runtime/02_main_loop.md](../02_runtime/02_main_loop.md)

## 背景

去掉 LangGraph 后，主循环的形态有两种选择。

## 选项

**A. 保留 planner / budget_guard / executor / tool_runner / evaluator 五阶段，用显式循环加路由表驱动。**

- 现有阶段函数、五个路由函数、提示词、里程碑语义和大部分测试可以原样复用。
- 迁移只替换"图引擎"那一层，风险集中在循环、检查点与审批。
- 代价：每一步经过两次推理档调用（规划与复核）的机会，Token 成本和延迟偏高。

**B. 简化为单一 ReAct 循环。**

- 代码更少，调用链更短，Token 成本更低。
- 里程碑、evaluator 的"已确认事实 / 失败尝试"沉淀、planner 与 evaluator 提示词都要重做，既有测试大量作废。
- 同时改引擎和认知结构，出问题时难以区分原因。

## 决定

选 A。先把引擎替换干净并通过现有行为测试，再单独评估是否把五阶段收敛成 ReAct，那是一个独立的、可对比的实验。

## 后果

- 路由函数保持纯函数，只把 `END` 换成 `DONE` 哨兵。
- 之后若要简化，只需替换 `stages` 与 `ROUTES` 两张表，循环、检查点、审批不受影响。这是选择显式路由表而不是把流程写死在循环体里的原因。
