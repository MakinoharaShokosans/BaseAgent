## 核心做法

1. **默认离线，确定，隔离。** 不访问网络，不使用真实密钥，存储指向临时目录；真实模型测试显式触发并带成本保护。
2. **每个已发现的缺陷先写失败的回归测试。** 文档集中记录的问题，都在 [测试矩阵 §10](02_test_matrix.md) 里有对应的测试名。
3. **把"已知防不住"写成严格 `xfail`。** 安全边界的局限用测试留案，被修复时提醒移除标记。
4. **用旧行为证明新实现。** 在旧引擎上冻结一组黄金场景的输出，新循环逐项对照，避免遗漏引擎的隐含语义。
5. **统计型评测与断言型测试分开。** 前者看分布与趋势，后者看对错。

## 优先级一览

- **P0**：安全与数据完整。实现某个子系统时必须同时交付。
- **P1**：核心行为。
- **P2**：增强。

全部 P0 通过是合并的底线。
