# 测试矩阵

把各份设计文档里的"测试要点"和"已发现的问题"收拢成一张清单，按子系统列出**必须有**的测试和优先级。实现时逐项勾选；某项做不到要写明原因。

优先级：**P0** 安全与数据完整，实现该子系统时必须同时交付；**P1** 核心行为；**P2** 增强。

## 11. 使用方式

- 实现某个子系统前，先把本表对应的 P0 测试写成骨架（可以先 `xfail`）。
- 每完成一项，在对应文档的"测试要点"里保持一致；表与文档不一致时，以更严格者为准，并同步另一方。
- 合并前检查：P0 全部通过；P1 通过或有明确的跟进事项；新增的缺陷有回归测试。
