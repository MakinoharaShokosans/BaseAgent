# 视觉与交互设计

控制台的信息密度很高：对话、回合时间线、工具往返、审批、记忆、上下文规模。本文给出界面的视觉语言与交互规则，目标是**一眼看懂状态、需要时才展开细节、动效只为传达变化**。

审批与安全相关的界面约束仍以 [02](02_approval_and_safety_ux.md) 为准；本文只改变它们的外观，不放宽任何一条。

## 1. 风格

**无边框、浅色、macOS 与 Instagram 气质。**

| 原则 | 落到界面上 |
|---|---|
| **无边框** | 卡片、输入台、下拉、气泡都不画描边。层次靠底色明度、柔和的大半径阴影、毛玻璃区分；分隔线只在同一张卡片内部、且极淡 |
| **浅色优先** | 缺省浅色，暖白底；暗色是完整的第二套，不是反色 |
| **macOS** | 半透明侧栏（vibrancy）、大圆角（卡片 18px，控件 10–12px）、细字重层级、克制的图标 |
| **Instagram** | 品牌渐变（橙 → 玫红 → 紫）只用在少数"活的"地方：发送按钮、当前对话节点、当前会话指示条、滑动条已选段、运行中光环 |
| **状态先于内容** | 运行、等待审批、完成要在顶栏和输入台同时可感知 |
| **渐进披露** | 时间线结束后收起、工具调用一行摘要、右侧卡片可折叠 |
| **安全提示不被美化掉** | 高危命令的红色、延迟启用、二次确认保持最高视觉权重 |
| **尊重系统偏好** | `prefers-reduced-motion` 时位移动画降级为淡入 |

## 2. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 界面与正文 | **Geist Variable** | 几何、紧凑、数字清晰 |
| 展示标题 | **Instrument Serif** | 只用在空状态大标题 |
| 代码与命令 | **Geist Mono Variable** | |
| 中文回退 | HarmonyOS Sans SC → MiSans → PingFang SC → Noto Sans CJK SC → 微软雅黑 | 中文走系统字体，避免数 MB 字体下载 |

字体由 `@fontsource` 本地打包，不请求外部 CDN。数字一律 `tabular-nums`。

## 4. 布局

```
┌────────────┬───────────────────────────────────────────┬─────────────────┐
│ 工作区   ⊕ │ 顶栏：工作区 / 会话 · 状态胶囊 · 检视器开关  │ ▾ 任务           │
│ ▾ BaseAgent  + │                                           │   计划进度     │
│    会话 2  │      对话（最大宽 760，居中）        ● 节点 │ ▾ 上下文占比     │
│    会话 1  │      Markdown 渲染                  ●      │   已用 / 窗口    │
│ ▸ temp   + │                                     ○      │   分段条与明细   │
│            │  ┌ 输入台（无边框浮层）──────────────────┐ │                 │
│ ☀   ⚙     │  │ 模型 ▾  权限 ▾                    ➤  │ │                 │
└────────────┴──┴──────────────────────────────────────┴─┴─────────────────┘
```

### 4.1 左侧栏

- **没有 Logo。** 顶部只有"工作区"标题和一个"新建工作区"图标按钮。
- 内容是**工作区 → 会话**的两级树。工作区是线条文件夹图标，会话是线条对话图标，不用彩色色块。每个工作区行右侧的 `+` 在其中新建会话（当前工作区常显，其余悬停显示）。
- **底部只有两个按钮**：浅色 / 暗色切换，设置（打开 §5）。
- 可折叠为 64px 图标条（`Ctrl/⌘ + B`），宽度弹簧动画。
- 当前会话有一条品牌渐变的指示条，切换时用共享布局动画滑过去；运行中或等待审批的会话右侧有状态点。
- 删除工作区不放在侧栏，移到设置面板的"当前工作区"分组（§5），仍需输入名称确认。

### 4.2 顶栏

面包屑 `工作区 / 会话 N`、状态胶囊（运行中有流光）、步数与 Token、事件流断开提示（不变量：断开对用户可见）、检视器开关（`Ctrl/⌘ + J`）。顶栏透明，不画底线。

### 4.3 右侧栏：可折叠卡片

| 卡片 | 内容 |
|---|---|
| **任务** | 当前任务（运行中取事件流，否则取会话最新一个任务的快照）：目标、状态、Agent 写下的计划及进度，回合数与 Token |
| **上下文占比** | 记忆与对话在上下文窗口中的占比，见 §7 |

每张卡片标题行点击折叠，高度动画；折叠状态记在本地偏好。窄屏（< 1100px）右侧栏改为覆盖式抽屉，缺省关闭。

## 5. 设置

左下角齿轮打开设置面板（模态，毛玻璃遮罩）。左侧是分组导航，右侧是内容：

| 分组 | 项 | 控件 | 来源 |
|---|---|---|---|
| **当前会话** | 模型 | 自定义下拉，选项来自 `GET /models` | `PUT /sessions/{id}/settings` 的 `model` |
| | 上下文上限 | **滑动条** + 数值，范围来自接口的 `bounds` | `context_token_limit` |
| **当前工作区** | 删除工作区 | 危险按钮 + 输入名称确认 | `DELETE /workspaces/{id}` |
| **系统提示词** | 系统提示词 | 等宽多行编辑框，字数计数，"恢复默认" | `PUT /settings` 的 `system_prompt` |
| **外观** | 主题 | 分段控件：跟随系统 / 浅色 / 暗色 | 本地偏好 |

- **凡是可以数值化的设置都用滑动条**：轨道浅色底，已选部分是品牌渐变，拇指是白色圆点带柔和阴影，拖动时放大并在上方显示数值气泡；支持方向键、Page Up/Down、Home/End；`role=slider` 与 `aria-valuenow/min/max`。
- **跨数量级的范围用对数刻度**（`Slider` 的 `scale="log"`）。上下文上限的范围是 4k 到最小窗口（如 1M），线性刻度下常用的 4k–64k 只占轨道 6%；对数刻度下约占一半，32k 的缺省值落在约 38% 处。对数刻度下键盘按位置走：方向键挪 1% 轨道，Page Up/Down 挪 10%，吸附后原地不动时至少走一个 step。
- 保存是显式的：有未保存改动时"保存"按钮才可用；保存成功有轻提示。设置在下一个任务生效，界面写明这一点。
- 接口的范围和缺省值是事实来源，前端不硬编码上下限。

## 6. 对话区

### 6.1 输入台

- 无边框浮层：白底、24px 圆角、大半径柔和阴影；聚焦时阴影加深。运行中周边有一圈缓慢旋转的渐变光。
- 底部一行：**模型下拉**（所选模型的渐变小圆点与名称）、**权限下拉**、提示文字、快捷键、发送按钮（品牌渐变圆形）。
- 模型列表**只来自 `GET /models`**，按端点名去重，显示端点名、模型 id 与上下文窗口；"自动"表示按配置顺序。选择立即写入会话设置（`PUT /sessions/{id}/settings`），刷新后保留，也与设置面板里的同一项一致。
- 完全权限仍然每次二次确认、不被记住。

### 6.2 自定义下拉

**所有下拉框都用自定义组件 `Select`，不用原生 `<select>`。**

- 触发器：无边框胶囊，文字 + 细箭头；展开时箭头旋转。
- 弹层：`raised` 底、14px 圆角、毛玻璃、柔和阴影，从触发器方向缩放淡入（160ms）；选项悬停有底色，已选项有对勾，可带说明文字。
- 键盘：Enter / Space / ↓ 打开，↑↓ 移动，Enter 选择，Esc 关闭并把焦点还给触发器，Tab 关闭。点击外部关闭。
- ARIA：触发器 `aria-haspopup="listbox"` 与 `aria-expanded`，弹层 `role=listbox`，选项 `role=option` 与 `aria-selected`。
- `placement` 可选向上或向下（输入台里的下拉向上）。

### 6.3 消息与 Markdown

- 用户消息：浅灰底圆角气泡，无边框；助手回复：不加气泡，直接排版在画布上。
- Markdown：正文 15px / 1.75 行高；标题有清晰的字重层级；行内代码浅底圆角；代码块深色圆角卡片，顶部一条显示语言与"复制"按钮；表格无竖线、表头浅底、行间极淡分隔；引用块左侧渐变细条；列表项间距放宽；链接下划线偏移。安全约束不变（不渲染原始 HTML、不加载外部图片、链接白名单）。

### 6.4 对话节点

- 每一轮对话（一条用户消息及其回复）是一个**节点**。对话区右缘有一条竖向节点轨道：每个节点是一个小圆点，当前可见的那一轮用品牌渐变放大显示。
- 悬停节点显示这一轮用户消息的摘要气泡；**点击节点平滑滚动到这一轮**。
- 当前轮由 `IntersectionObserver` 判定，不逐帧监听滚动。
- 对话区**隐藏滚动条**（`scrollbar-width: none` 与 `::-webkit-scrollbar { display: none }`），鼠标滚轮、触控板、键盘滚动照常可用；节点轨道承担"我在哪里"的定位作用。

## 7. 上下文占比

右侧第二张卡片，回答两个问题：**记忆和对话一共占了上下文窗口的多少**，以及**每一类各占多少**。

```
上下文占比 ▾                               +
0.1% 已用                       1.2k / 1M
▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬
■ 项目概况        320     <0.1%
■ 规范与约定      410     <0.1%
…
■ 对话记录        820     <0.1%
■ 剩余空间      998.8k    99.9%
```

1. **分母**：会话所选模型的 `context_window`；未选时取已装配端点里的最小值。拿不到时只显示 Token 总量。
2. **分子**：每类内容的 Token 估算之和，规则与后端 `llm/tokens.py` 的 `estimate_tokens` 一致（中日韩字符一字一 token，其余每 3 字符一 token），实现在 `utils/text.ts`，两边改动要同步。
3. **行**：工作区记忆四层、会话记忆四类、对话记录（最近载入的对话轮次）、剩余空间。有条目的行可展开；工作区记忆的条目可删除；卡片右上角 `+` 新增记忆（层级用自定义下拉）。
4. 会话的"上下文上限"（§5）显示在卡片底部："对话超过 32k 时压缩"。

## 8. 动效

所有动效通过 `motion` 实现，根节点包 `MotionConfig reducedMotion="user"`。

| 令牌 | 值 | 用途 |
|---|---|---|
| `fast` | 120ms | 悬停、按下 |
| `base` | 220ms | 淡入、折叠、下拉 |
| `slow` | 420ms | 面板宽度、模态 |
| 曲线 `out` | `cubic-bezier(.22,1,.36,1)` | 进入 |
| 弹簧 | stiffness 380, damping 34 | 面板宽度、指示条 |

| 场景 | 动效 |
|---|---|
| 新消息、新时间线条目 | 从下方 8px 淡入上浮 |
| 工具调用 运行中 → 完成 | 旋转弧变为描边绘制的对勾 |
| 折叠区、右侧卡片 | 高度自动动画，箭头旋转 |
| 下拉弹层 | 自触发器方向缩放淡入 |
| 滑动条 | 拇指按下放大，数值气泡弹出 |
| 对话节点 | 当前节点放大并切换为渐变；点击后平滑滚动 |
| 运行中 | 状态胶囊流光、输入台渐变光环、背景光晕呼吸 |
| 等待审批 | 琥珀色光圈呼吸；审批卡片轻微缩放进入，**不抖动** |

**禁止**：审批按钮上任何吸引点击的动画；打字机效果；超过 420ms 的阻塞性过渡。

## 9. 图标

- 通用操作用 `lucide-react` 线条图标（1.6–1.75 描边，16/18px）。
- 语义图标自绘（`components/icons/Glyphs.tsx`）：24 网格、1.6 描边、圆角端点，可带动画。
- 图标只用线条，不做彩色色块填充。装饰性 SVG 一律 `aria-hidden`。

## 10. 无障碍

- 所有交互元素键盘可达，焦点环可见。
- 自定义下拉与滑动条实现完整的 ARIA 角色与键盘操作（§5、§6.2）。
- 状态同时用图标、文字、颜色表达。
- 隐藏滚动条不影响滚动；节点轨道的按钮有可访问名称（"跳到第 N 轮"）。

## 12. 验收

- 现有单元测试全部通过；自定义下拉、滑动条有组件测试；后端设置接口有路由测试。
- 浅色与暗色下检查：空状态、对话中、运行中、等待审批（含高危）、设置面板、右侧两张卡片、侧栏折叠形态。
- 打开系统"减少动态效果"后，界面无位移动画，状态仍可辨认。
