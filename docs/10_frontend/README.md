# 前端控制台

用户与 Agent 之间唯一的界面：看进度、做审批、管理工作区与记忆。前端是服务端状态的投影，不持有业务事实的权威副本，也不做任何编排决策。

## 前端承担的安全职责

前端是最后一道门：它决定用户能不能看清自己在批准什么，也决定来自模型和网页的内容会不会在用户的浏览器里被当作代码执行。所以安全相关的界面行为都当作**契约**，有测试固定下来。
